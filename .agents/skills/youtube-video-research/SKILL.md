# YouTube Video Research

Leverage YouTube as a primary source of first-hand information for research tasks. YouTube hosts CEO interviews, founder keynotes, earnings calls, expert panels, conference talks, product demos, practitioner vlogs, cultural documentaries, policy discussions, technical deep-dives, and educational content that contain unfiltered, first-person insights unavailable in text articles.

## Core Workflow

### Step 1: Theme-Based Video Discovery
- Identify 4-6 research themes from the user's request.
- Run targeted YouTube search queries per theme.
- Target 12-20 videos for deep research, 8-12 for standard research.
- Include query variants with terms: interview, keynote, panel, talk, conference, review, demo.

### Step 2: Select and Prioritize Videos
- **Highest Priority**: First-person subject/expert speaking directly (keynote, interview, conference talk).
- **High Priority**: Expert/insider perspective (industry analyst, practitioner, researcher).
- **Medium Priority**: High quality third-party documentary, investigative review.
- Actively seek opposing viewpoints (at least 30% critical/counter-arguments).

### Step 3: High-Density Prompt Engineering
- NEVER use generic prompts like "summarize this video".
- Demand direct verbatim quotes (at least 8-10 quotes).
- Extract all data points, numbers, dates, dollar amounts, metrics, names.
- Use structured sections: (A) Speaker Profile, (B) Direct Quotes, (C) Data Points, (D) Key Arguments, (E) Counter-Arguments/Risks, (F) Sentiment.

### Step 4: Cross-Validate with Web Search
- Verify factual claims made in videos.
- Fill gaps in dates, statistics, and historical context.
- Cross-validate against independent documentation or literature.

### Step 5: Synthesize into Report
- Include direct blockquote citations attributed with numeric citations [1].
- Expand key findings into substantive paragraphs with context, numbers, quotes, and implications.
- Multi-source triangulation: weave perspectives into a dialogue rather than a sequential list.
- Include a Source Videos Analyzed table and complete References section.
